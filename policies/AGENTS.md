# AGENTS.md — policies/

Policy files here are engineering constraints, not suggestions. They must not be
weakened simply to make an implementation pass — if a policy blocks legitimate
work, that's a signal to raise/resolve it explicitly (e.g. via a new ADR), not to
edit the policy quietly as a side effect of unrelated work.

See [`README.md`](./README.md) in this directory for the current rule set.
