# `make help`

## What it does

Prints [`check-prereqs`](./make-check-prereqs.md) and
[`bootstrap`](./make-bootstrap.md), each with a one-line description.

## Why it exists

A no-argument-friendly discovery command for the `Makefile`, mirroring
`task`'s own no-argument behavior.

## How to use it

```bash
make help
```
